# 近视防控工具箱

一个面向近视防控与视力管理的轻量化前端工具箱，适合个人使用，主要用于记录、评估和复盘近视防控过程。项目以静态 HTML 页面为主，运行简单，数据保存在本地浏览器中，不依赖后端服务。

在线访问：https://maggiec87.github.io/vision-kits/

## 项目简介

本项目聚焦于近视防控日常管理，帮助用户在以下方面进行辅助记录和分析：

- 近视度数估算
- 视力训练与练视力表
- 日常防控记录与复盘
- 视功能训练数据记录
- 眼科检查数据记录
- 防控知识笔记
- 防控花费统计
- 镜片与眼镜更新记录

## 功能模块

### 1. 度数测算
- 根据生物测量数据估算近视度数
- 便于快速评估视力变化趋势

### 2. 练视力表
- 提供 6 米雾视训练相关内容
- 适合用于裸眼视力提升练习

### 3. 防控日记
- 记录每日户外活动、拉近/拉远训练、作息等信息
- 便于后续复盘与总结

### 4. 视训记录
- 记录视功能训练过程中的关键数据
- 便于观察训练效果和持续性

### 5. 检查记录
- 记录眼轴、验光、视功能等检查信息
- 适合长期管理视力相关数据

### 6. 防控笔记
- 记录个人学习到的防控知识与技巧
- 方便整理零碎信息

### 7. 防控账单
- 统计近视防控相关支出
- 方便查看费用变化和投入成本

### 8. 多少眼镜
- 记录眼镜更新、更换和佩戴情况
- 用于跟踪视觉矫正管理进度

## 使用方式

### 本地查看
1. 下载或克隆本仓库
2. 在浏览器中打开 `index.html`
3. 或者直接访问 GitHub Pages：
   https://maggiec87.github.io/vision-kits/

### 注意事项
- 本项目为静态前端页面，默认不含后端数据库
- 数据存储在浏览器本地，关闭页面或清理缓存可能影响数据保留
- 建议定期备份重要记录

## 说明
