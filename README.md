# vision-kits — 近视防控工具箱

> 近视防控与视力管理的静态前端工具箱

在线使用：https://maggiec87.github.io/vision-kits/

---

这个小项目是我为日常近视防控和视力管理做的工具集合，最初是为自己/家人使用而做的轻量化页面集合。项目不依赖后端，所有数据保存在浏览器本地（localStorage），方便随用随看、也便于本地备份。

主要页面（速览）

- 度数测算（degree_calculator.html） — 根据生物测量数据做简单估算
- 练视力表（better_vision.html） — 用于裸眼视力练习的视力表页面
- 防控日记（daily_tracker.html） — 记录每日活动与训练情况
- 视训记录（visual_function_training.html） — 记录视功能训练数据
- 检查记录（check_data.html） — 记录眼轴、验光等检查数据
- 防控笔记（notebook.html） — 零碎知识点与经验总结
- 防控账单（cost.html） — 花费与投入统计
- 多少眼镜（glasses.html） — 眼镜更换/更新记录

设计理念

- 以“记录”和“复盘”为核心：把每天的训练/检查/花费等结构化存档，方便长期观察变化趋势；
- 简单、离线优先：纯静态页面，数据保存在浏览器，适合个人隐私和快速使用；
- 实用为主：界面轻量，功能直观，便于在手机或平板上随手记录。

技术栈

- HTML / CSS（主要）
- 少量 JavaScript（主题切换、localStorage 交互等）

关于数据

- 项目默认将数据保存在浏览器本地（localStorage）
- 清除浏览器缓存或切换设备会导致数据不可用，请自行备份重要记录
